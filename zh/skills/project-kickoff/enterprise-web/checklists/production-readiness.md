# 生产就绪检查清单

> **用途**: 上线前的最终检查，确保系统满足生产环境要求  
> **使用时机**: 部署到生产环境之前  
> **原则**: 全部 P0 必须通过，P1 强烈建议通过，P2 按项目情况决定

| 检查项 | 优先级 | 说明 | ✓ |
|--------|:------:|------|:-:|

## 使用说明

1. **上线前 1-2 天**：逐项检查，记录状态
2. **P0 全部通过**才能上线
3. **P1 未通过项**需要明确的修复计划和时间表
4. **P2 未通过项**记录到 open-issues，后续迭代处理
5. **检查结果存档**，作为上线审批的依据
